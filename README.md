# Storm Animation with Next.js & Framer Motion

A beautiful rain and thunderstorm animation built with Next.js, React, and Framer Motion.

## Features

- 🌧️ Smooth rain drops animation
- ⚡ Random lightning effects
- ☁️ Moving clouds
- 📝 Auto-sliding text sections
- 🎨 Beautiful gradient backgrounds
- ✨ Fully responsive

## Tech Stack

- Next.js 14+
- React 18+
- Framer Motion
- Tailwind CSS
